# 📘 Инструкция для совсем новичка

Запуск монитора funding Bybit с нуля: установка, запуск, расшифровка результата.
Время на всё: ~20 минут. Умение программировать: **не нужно**.

---

## Что мы вообще запускаем и безопасно ли это

`funding_monitor.py` — это программа, которая **только читает** публичные данные
с биржи Bybit (цены, ставки финансирования, объёмы) и печатает красивый отчёт.

✅ Чего она **НЕ** делает:
- не требует аккаунт Bybit (на этом этапе он вообще не нужен)
- не требует API-ключи, пароли, логины
- не может ничего купить, продать или перевести — у неё физически нет такой возможности
- не просит денег

То есть сломать или потерять что-то невозможно. Худшее, что случится — ошибка
в тексте, и мы её разберём в разделе «Если что-то пошло не так».

## Шаг 1. Установить Python

Python — это бесплатная программа, которая умеет запускать скрипты.

### Windows

1. Откройте сайт **https://www.python.org/downloads/** и нажмите большую жёлтую
   кнопку «Download Python 3.x.x».
2. Запустите скачанный файл.
3. ⚠️ **САМЫЙ ВАЖНЫЙ МОМЕНТ ВСЕЙ ИНСТРУКЦИИ:** на первом экране установщика
   поставьте галочку **«Add python.exe to PATH»** (внизу окна). Без неё
   компьютер не будет понимать команду `python`.
4. Нажмите «Install Now», дождитесь конца, закройте.

Проверка: нажмите `Win + R`, наберите `cmd`, нажмите Enter. В чёрном окне введите:

```
python --version
```

Если ответило что-то вроде `Python 3.12.4` — всё получилось.
Если «не является внутренней или внешней командой» — см. раздел «Частые ошибки» ниже.

### macOS

1. Тот же сайт **python.org/downloads/** → скачать → установить (там всё просто, «Далее-Далее»).
2. Проверка: откройте программу «Терминал» (Cmd+Пробел → напишите Terminal) и введите:

```
python3 --version
```

На Mac команда называется `python3` (с тройкой на конце).

## Шаг 2. Положить скрипт в папку

1. Создайте на компьютере папку, например:
   - Windows: `C:\bybit-funding`
   - Mac: `~/bybit-funding` (или на Рабочем столе)
2. Скачайте файл **`funding_monitor.py`** из этого чата (в просмотрщике файлов
   есть кнопка скачивания) и положите его в эту папку.

> Альтернатива, если скачать не получается: откройте `funding_monitor.py` здесь,
> скопируйте весь текст, на компьютере создайте текстовый файл, вставьте текст и
> сохраните его под именем `funding_monitor.py`. Важно: при сохранении в
> Блокноте выберите «Тип файла: Все файлы», иначе Windows добавит `.txt` и
> получится `funding_monitor.py.txt` — это не сработает.

## Шаг 3. Открыть терминал в этой папке

Терминал — это окно, где командами говорят с компьютером. Не бойтесь его.

### Windows (простой способ)

1. Откройте проводник, зайдите в папку `C:\bybit-funding`.
2. Кликните в **адресную строку** сверху (где написан путь к папке), сотрите всё,
   напишите `cmd` и нажмите Enter.
3. Откроется чёрное окно — и оно уже «стоит» в нужной папке.

### Windows (классический способ)

1. `Win + R` → `cmd` → Enter.
2. Перейдите в папку командой `cd` (change directory):

```
cd C:\bybit-funding
```

### macOS

1. Откройте Терминал.
2. Введите `cd ` (с пробелом на конце) и **перетащите папку** из Finder прямо
   в окно терминала — путь подставится сам. Нажмите Enter.

---

## Шаг 4. Запустить!

В терминале, находясь в папке со скриптом, введите:

**Windows:**
```
python funding_monitor.py
```

**macOS / Linux:**
```
python3 funding_monitor.py
```

Нажмите Enter. Через 5–15 секунд (программа опрашивает биржу) появится отчёт.
Первый запуск может спросить разрешение на доступ в интернет — разрешите.

## Что вы увидите на экране (расшифровка по-человечески)

Отчёт выглядит примерно так (цифры у вас будут другие — они живые и меняются):

```
СИМВОЛ        ИНТР    СТАВКА   APY 7д   APY 30д  +30д    БАЗИС   ВХОД   ОКУП      OI    ЛИКВ  ВЕРДИКТ
XMRUSDT         8ч  +0.0100%   +11.0%    +19.4%  100%      нет  0.31%     6д  $37.1M средняя  ✗ нет спот-ноги
BTCUSDT         8ч  +0.0049%    +3.8%     +4.4%   88%  -0.055%  0.36%    30д  $4.97B высокая  ✗ низкая ставка; базис -0.055%
```

Простыми словами:

| Колонка | Что значит |
|---|---|
| **СИМВОЛ** | монета. BTCUSDT = биткоин |
| **ИНТР** | как часто биржа выплачивает funding: каждые 8ч или 4ч |
| **СТАВКА** | ставка ближайшей выплаты. `+0.0100%` = держа шорт на нотион $1000, получишь ~$0.10 за выплату |
| **APY 7д / APY 30д** | средняя годовая ставка за неделю / месяц. **APY 30д — самая честная цифра** |
| **+30д** | в скольких % интервалов ставка была плюсовой. 100% = платили всегда |
| **БАЗИС** | насколько перп дороже (+) или дешевле (−) спота. Входить выгодно при ≥ 0. `нет` = спота этой монеты на Bybit нет — захеджировать нечем, бот такое не берёт |
| **ВХОД** | полная стоимость круга: комиссии + спреды + невыгодный базис, % |
| **ОКУП** | за сколько дней ставка отобьёт стоимость входа |
| **OI / ЛИКВ** | сколько денег в монете и уровень риска: «высокая» — норм, «НИЗКАЯ» — опасно |
| **ВЕРДИКТ** | взял бы бот этот символ: `✓ ГОДЕН` или `✗` с причиной |

Ниже таблиц будут три блока портфелей — сколько бы вы зарабатывали на условные
$1000 с вычтенными комиссиями: **«✅ ПРОШЛИ ФИЛЬТР»** (что бот держал бы прямо
сейчас), **«ТОП без фильтра»** (для сравнения) и **«МЕЙДЖОРЫ»**. Если блок
«прошли фильтр» пустой — это не ошибка, а дисциплина: в тихом рынке бот должен
сидеть в стейблкоинах и ждать подходящих окон.

### Главное правило чтения отчёта

Чем выше APY — тем больше риск, что это ловушка. Ставки в **десятки и сотни %**
у ноунейм-монет — это не халява, а плата за риск (и часто у них вообще нет
спот-ноги — колонка ВЕРДИКТ это покажет). Доверяйте символам, где APY 30д
умеренный, «+30д» высокий (80–100%), базис ≥ 0, окупаемость короткая, а
вердикт — `✓ ГОДЕН`.

## Шпаргалка полезных команд

Всё вводится в терминале в папке со скриптом:

```bash
# базовый отчёт
python funding_monitor.py

# топ-20 возможностей и расчёт на депозит $5000
python funding_monitor.py --top 20 --capital 5000

# посмотреть только конкретные монеты
python funding_monitor.py --symbols BTCUSDT,ETHUSDT,SOLUSDT

# режим наблюдения: обновляет отчёт каждые 60 минут (остановка — Ctrl+C)
python funding_monitor.py --watch 60

# сохранить данные в файл (чтобы копить историю наблюдений)
python funding_monitor.py --json snapshot.json

# сделать фильтр жёстче: ставка от 15% годовых, окупаемость до 10 дней
python funding_monitor.py --min-apy30 15 --max-breakeven 10

# режим охоты на аномалии: текущий APY от 30%, окуп до 3 дней, OI от $50M
python funding_monitor.py --preset spike
```

Флаги можно сочетать:
```bash
python funding_monitor.py --top 15 --capital 3000 --watch 120 --json snap.json
```

На Mac везде замените `python` на `python3`.

## Если что-то пошло не так (частые ошибки)

**«python не является внутренней или внешней командой» (Windows)**
→ Не поставили галочку «Add python.exe to PATH» при установке. Два решения:
  1. Проще: попробуйте команду `py` вместо `python`: `py funding_monitor.py`
  2. Правильно: переустановите Python, поставив галочку PATH.

**Открывается Microsoft Store вместо Python**
→ Параметры Windows → «Псевдонимы выполнения приложений» → выключите
переключатели «python.exe» и «python3.exe» (App Installer).

**«No such file or directory: funding_monitor.py»**
→ Терминал открыт не в той папке. Перейдите в папку командой `cd` (см. Шаг 3)
и проверьте, что файл лежит именно там (команда `dir` покажет содержимое папки
на Windows, `ls` — на Mac).

**Файл называется `funding_monitor.py.txt`**
→ Блокнот добавил расширение. Переименуйте файл (в проводнике включите вид
«Расширения имён файлов»: Вид → Показать → Расширения имён файлов).

**«URLError», «timed out» или скрипт висит и ничего не выводит**
→ Проблема с интернетом или доступом к api.bybit.com из вашего региона/сети.
Попробуйте выключить VPN (или наоборот включить), другую сеть. Публичный API
Bybit доступен почти отовсюду, но корпоративные/провайдерские блокировки бывают.

**Отчёт выводится, но в консоли каша из букв**
→ В Windows-терминале переключитесь на PowerShell или Windows Terminal
(вместо старого cmd) — они нормально показывают юникод.

**Как остановить режим --watch?**
→ Нажмите в терминале `Ctrl + C`.

## Правила безопасности (прочитайте обязательно)

1. **Никогда и никому не передавайте API-ключи** от биржи. Когда дойдёте до
   настоящего бота — создавайте ключ **без права вывода средств** (только чтение + торговля).
2. Биржевые аккаунты регистрируйте **только на официальном сайте bybit.com**.
   Фишинговых клонов очень много.
3. Никто в Telegram/YouTube **не продаёт «прибыльных ботов»**. Человек с реально
   прибыльным ботом зарабатывает им сам, а не продаёт за $50. Любые предложения
   «переведи деньги, мой бот будет торговать за тебя» — это скам.
4. Монитор, который вы запустили — безопасная читалка. Но **реальная торговля —
   риск потери денег**. Начинайте только с testnet (бумажные деньги) и только
   с сумм, которые не жалко.

## Что делать дальше (план на 2–3 недели)

1. **Неделя 1–2: наблюдение.** Запускайте монитор раз в день (или оставьте
   `--watch 60` работать). Каждый раз сохраняйте снимок:
   `python funding_monitor.py --json snap.json` — и просто смотрите, как меняются
   ставки. Вы увидите главное: сегодняшние «топы» через неделю остывают.
2. Заведите блокнотик: выписывайте 2–3 символа с высоким APY 30д и хорошей
   ликвидностью, и сверяйте через несколько дней — угадали ли вы?
3. Когда насмотритесь — создайте аккаунт на **testnet.bybit.com** (это копия
   биржи с игрушечными деньгами) и напишите мне — соберём следующий уровень:
   бота, который сам открывает дельта-нейтральную позицию на тестовых деньгах.
